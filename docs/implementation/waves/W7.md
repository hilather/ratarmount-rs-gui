## Honest status (2026-08-30)

Scripts, icons, nfpm Depends, layout tests, and a tag-job dry-run are landed. Tests: `bash packaging/run-tests.sh`.

**Not claimed:** a portable Linux tarball and a macOS arm64 `.app` that run on a clean machine and open a TAR. That still needs a compiled GPUIX GUI binary plus in-process `ratarmount-session` (engine G0–G2). Engine CLI assets for tag `v0.1.29` exist and `packaging/fetch-engine-cli.sh` can download them; the CLI is **not** a list/extract backend and this PR does **not** invent a stub CLI to ship.

Cosign is wired on tag `v*` when real blobs exist (OIDC). Apple notarize runs only with `CODESIGN_IDENTITY` / notarytool keys; otherwise skip and document Right-click → Open.

The tag job treats an empty `release/` as a no-op (`release-asset-filter.sh` prints zero lines). Packed `.deb` `Depends:` is asserted with `dpkg-deb` when nfpm is available. WiX 4 writes HKCU associations; WiX 3 candle/light is not used.
