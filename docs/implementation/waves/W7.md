## Honest status (2026-09-04)

Scripts, icons, nfpm Depends, layout tests, and a tag-job dry-run are landed. Tests: `bash packaging/run-tests.sh`. `packaging/engine-pin` is **`0.1.30`**, matching the `ratarmount-session` git tag in `native/Cargo.toml`. Distro yaml is `Depends: ratarmount (>= 0.1.30)`. Production open/list uses in-process `ratarmount-session`; the bundled CLI is **not** a list/extract backend.

**Not claimed:** a portable Linux tarball and a macOS arm64 `.app` that run on a clean machine and open a TAR. That still needs a compiled GPUIX GUI binary in packaging CI. `packaging/fetch-engine-cli.sh` fetches pin-matched assets for `v0.1.30`; if GitHub release assets are missing the script **fails closed**. Standalone scripts still refuse to invent a stub CLI.

Cosign is wired on tag `v*` when real blobs exist (OIDC). Apple notarize runs only with `CODESIGN_IDENTITY` / notarytool keys; otherwise skip and document Right-click → Open.

The tag job treats an empty `release/` as a no-op (`release-asset-filter.sh` prints zero lines). Packed `.deb` `Depends:` is asserted with `dpkg-deb` when nfpm is available. WiX 4 writes HKCU associations; WiX 3 candle/light is not used.
