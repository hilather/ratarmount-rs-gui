# W4 — Extract, preview, jobs

**Owner:** **one agent** covering UI + native (default). Split only with an explicit file split (`native/` vs `app/`) in the spawn prompt.  
**Depends on:** W2, W3  
**Done when:** selected files extract to a picked folder; small text/images preview; jobs cancelable; encrypted archives prompt for a password.  
**PR:** PR 5

## Tasks

- [ ] Multi-select in the list
- [ ] Extract to… (`pickDir` + `extractPlan` + `extract`). Native `extract.overwrite` is `'skip' | 'replace'` only; `'ask'` is UI-only
- [ ] Progress modal/panel bound to `extractProgress`; `jobFailed.retryable` drives Retry
- [ ] Cancel button
- [ ] Preview pane: `preview` command only
- [ ] If `skipped: too-large`, button “Extract and open with system”
- [ ] Path-escape members: surface `PathEscape`, do not write
- [ ] Confirm when extract-all and (files > 1000 or bytes > 1 GiB) via `extractPlan` (`files`/`bytes`/`conflictCount`; never bind the full `conflicts` array as list state)
- [ ] Password modal on `BadPassword`: retry `open` with password. Password exists in JS **only for that call** — not React state, not config, not logs
- [ ] Tests: extract fixture member; preview a <1 KiB text file; **default 8 MiB config refuses a 9 MiB member** (this is the default cap, not the 64 MiB ceiling)
- [ ] Test: extract-all `extractPlan` on a 1k fixture with 1k planted dest conflicts returns `conflicts.length ≤ 50`, `conflictsTruncated === true`, and `conflictCount ≥ 50`. Do not put 1k paths into the page.

## Hard rule

No new napi method that returns the whole member. Do not pass `'ask'` to native `extract`.
