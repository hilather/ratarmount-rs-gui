## Hard rule

No new napi method that returns the whole member. Do not pass `'ask'` to native `extract`.

## Engine gap

- [x] Production `preview` / `extract` / `extractPlan` of real archive bytes go through in-process `ratarmount-session` 0.1.30 (`read_range` / `extract_to`). Fake catalog / `RGUI_FAKE=1` stays for UI tests.
- Native still clamps preview (default 8 MiB, ceiling 64 MiB). A 9 MiB member is skipped **without** `read_range`. No `readAll`. Native `extract` still rejects `'ask'`.
- Image decode/resize is still skipped (`unknown`). Text preview is lookup-then-`read_range` (NUL → `binary`, else lossy UTF-8).
- Selected directories are expanded on the extract worker (files only) after dropping `Mutex<NativeApp>`. Empty `members` is engine extract-all. Engine pending extract stores `Arc<Session>` + unexpanded paths — never `body: Vec<u8>`.
